# رنگارنگ — Rangarang 🎨

اکستنشن کروم مستقل برای مدیریت پالت رنگ. بدون PHP، سرور یا دیتابیس — تمام دادهها در `chrome.storage.local` ذخیره میشوند.

## نصب

1. کروم را باز کرده و به `chrome://extensions` بروید.
2. «حالت توسعهدهنده» (Developer mode) را فعال کنید.
3. «بارگذاری بازشده» (Load unpacked) بزنید و پوشهٔ `extension` را انتخاب کنید.

روی آیکون رنگارنگ در نوار ابزار کلیک کنید تا اپ در یک تب کامل کروم باز شود.

## قابلیتها

همان قابلیتهای نسخهٔ وب: ساخت/ویرایش/حذف پالت، اضافه و ویرایش رنگ، ستاره، روشن/تیره کردن، جابجایی با کشیدن، جستجو (Ctrl+K)، منوی راستکلیک، تم روشن/تیره، خروجی CSS/SCSS/JSON/Tailwind/TXT و درونریزی و خروجی کامل JSON.

دادهها فقط روی دستگاه شما هستند. از دکمهٔ «خروجی همه» برای تهیهٔ پشتیبان JSON استفاده کنید.
