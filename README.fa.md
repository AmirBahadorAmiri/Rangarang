# رنگارنگ (Rangarang) 🎨
### اکستنشن کروم برای مدیریت پالت رنگ، کاملاً محلی

**رنگارنگ** اکستنشنی برای کروم است که با آن می‌توانید پالتهای رنگ بسازید، مرتب کنید و خروجی بگیرید — تماماً داخل مرورگر. نه سرور PHP هست، نه دیتابیس؛ همهٔ پالتها روی دستگاه شما میمانند.

## 🌟 ویژگیهای کلیدی

### 📋 مدیریت پالت
*   ساخت، تغییر نام و حذف پالتها و رنگهای داخل آنها.
*   **جابجایی با کشیدن:** رنگها را دقیقاً به ترتیبی که میخواهید بچینید.
*   ستارهدار کردن رنگهای مهم و پیدا کردن هر چیزی با جستجوی Ctrl+K.

### 🎨 ابزار رنگ
*   افزودن رنگ با کد HEX یا انتخابگر رنگ داخلی.
*   روشنتر و تیرهتر کردن رنگ به میزان ۱۰٪ از منوی راستکلیک.
*   نمایش خودکار RGB، HSL و نام فارسی خانوادهٔ رنگ روی هر نمونه.

### 💾 خروجی و پشتیبان
*   خروجی پالت بهصورت CSS Variables، SCSS، JSON، Tailwind یا TXT.
*   **پشتیبان کامل JSON:** خروجی گرفتن از همهٔ پالتها در یک فایل و درونریزی دوبارهٔ آن.
*   رنگهای نامعتبر هنگام درونریزی JSON رد شده و تعدادشان اعلام میشود.

### 🔎 رابط کاربری
*   رابط کاملاً RTL فارسی با هدر چسبندهٔ پالت.
*   تم روشن و تیره با تشخیص خودکار تنظیمات سیستم.
*   منوی راستکلیک اختصاصی برای عملیات سریع روی رنگ و پالت.

## 🛠 تکنولوژیهای استفاده شده

رنگارنگ با تکنولوژیهای سادهٔ وب و APIهای اکستنشن کروم ساخته شده است:

*   **زبان:** JavaScript (بدون مرحلهٔ بیلد)
*   **معماری:** Chrome Extension Manifest V3 همراه با background service worker
*   **ذخیرهسازی:** chrome.storage.local (همهٔ پالتها روی دستگاه شما میمانند)
*   **رابط کاربری:** HTML5، CSS3، JavaScript خالص
*   **طراحی:** تم روشن/تیرهٔ RTL فارسی با لهجههای شیشهای
*   **بکاند:** هیچ — بدون سرور و دیتابیس

## 🚀 راهنمای نصب و اجرا

۱. ابتدا پروژه را از GitHub کلون کنید:
```bash
git clone https://github.com/AmirBahadorAmiri/Rangarang.git
```
۲. کروم را باز کرده و به `chrome://extensions` بروید.
۳. **حالت توسعهدهنده** (Developer mode) را از گوشهٔ بالا سمت راست فعال کنید.
۴. روی **Load unpacked** کلیک کرده و پوشهٔ `extension` را انتخاب کنید.
۵. روی آیکون رنگارنگ در نوار ابزار کلیک کنید تا اپ در یک تب کروم باز شود.
